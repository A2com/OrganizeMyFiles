# Rapport preprod — OrganizeMyFiles

**Date :** 2026-11-23 (mise à jour après corrections)
**Auditeur :** agent OpenCode (skill `preprod`), puis corrections et revérification
**Version auditée :** `main` = `1f99bfc` (PR #56, #57, #58, #59 et #60 fusionnées) ; version `0.2.1` (`app/Cargo.toml`)
**Environnement testé :** dépôt local `/srv/ssd/Projets Git/OrganizeMyFiles`, Mac Studio (`.dmg` 0.2.1, builds de contrôle)
**Verdict :** **GO conditionnel** — plus aucun bloquant ; majeurs restants listés avec plan et responsable.

> Historique : le premier passage (même date) était **NO-GO** pour trois bloquants (F1, O3, O4). Ils sont corrigés,
> revérifiés et fusionnés ; voir § 4.

## 1. Périmètre

- **Type de projet :** application de **bureau** native macOS (Rust + egui/eframe), distribuée en `.dmg`. Aucun serveur, aucune API exposée, aucun compte utilisateur, aucun paiement, aucun téléversement.
- **Stack :** Rust 2021, `eframe` 0.29.1 / `egui`, `notify` 9.0.0 (surveillance de dossiers), `rfd` 0.18 (sélecteurs), `image`, `serde`/`serde_json`, `chrono`, `tray-icon`/`muda`/`objc2` (menus et notifications macOS). Programme Swift embarqué `omf-extract` (PDFKit + Vision). Données : `~/Library/Application Support/OrganizeMyFiles/state.json` (+ `state.json.bak`), journal `~/Library/Logs/OrganizeMyFiles/journal.log`.
- **Environnements :** pas de production hébergée. Le Mac Studio sert aux builds et aux contrôles. Dépôt GitHub **privé**, **aucune release** publiée (`gh release list` vide) : la mise à jour intégrée n'est pas encore active chez les utilisateurs.
- **Signature :** « ad hoc », sans compte Apple Developer — **décision assumée le 2026-11-23** (voir X5). Conséquence : macOS ne peut pas attester l'origine de l'appli ni de ses mises à jour ; le premier lancement demande clic droit › Ouvrir.
- **Audité :** secrets (fichiers, historique, binaire livré), chaîne de mise à jour, exécution de commandes système, manipulations de fichiers, dépendances Rust (RustSec), CI, permissions macOS, résidus de test, échec sûr, journalisation, migration de format, retour arrière et restauration.
- **Non audité :** chaîne de notarisation (inexistante par décision), premier lancement Gatekeeper chez un utilisateur final, build Intel, réglages TCC de macOS, analyse dynamique d'`omf-extract`.

## 7. Reproduire

```bash
bash ~/.config/opencode/skills/preprod/scan.sh .
git log -p --all | grep -nIE 'AKIA[0-9A-Z]{16}|ghp_[A-Za-z0-9]{36}|BEGIN .*PRIVATE KEY'
git ls-files | grep -Ei '\.env|\.pem$|\.key$|id_rsa|\.sql$|wp-config'
cd app && TMPDIR=/srv/ssd/.omf-tmp CARGO_TARGET_DIR=/srv/ssd/.omf-target cargo test   # 162 tests
cd app && cargo tree --target aarch64-apple-darwin -i url
ssh mac-studio 'codesign -dv /Applications/OrganizeMyFiles.app; spctl --status'
```

Analyse des dépendances : `app/Cargo.lock` comparé à `rustsec/advisory-db`, script local `/tmp/opencode/audit-rustsec.py` (non versionné).
